# Design

## Approach

Baseline фиксирует уже существующее поведение, а не проект нового. Источники:

- `README.md`, `DOCS.md`, `DEVELOPMENT.md`, `SECURITY.md`;
- `src/main.cpp`, `src/webserver/webserver.cpp`, `src/setup/serialSetup.cpp`;
- `vue/public/default.json`, `vue/public/protocol.json`, `vue/src/pages/*`.

Спеки описывают наблюдаемые контракты: HTTP-маршруты, формат файлов, состояния
UI и реакции на ошибки. Имена классов, функций и внутренние структуры в спеки
не попадают.

## Capability boundaries

| Capability | Отвечает за | Не отвечает за |
|---|---|---|
| `firmware-runtime` | boot, config, WiFi, HTTP/WS, OTA, recovery | dashboard JSON и вёрстку UI |
| `web-interface` | SPA, страницы, темы, demo/dev, сборка UI | прошивку и OTA |
| `device-profile` | файлы LittleFS и их контракт | рендеринг dashboard |

Кросс-репозиторные контракты (бинарный протокол, dashboard schema, manifest
модулей) остаются в store `vuesp-workspace`. Локальные спеки ссылаются на них,
но не дублируют.

## Decisions

1. **Один baseline-change, три capability.** Дробление на большее число спек
   создаёт искусственные границы; три области совпадают с реальным делением
   репозитория.
2. **Ошибка конфигурации не блокирует устройство.** Невалидный `dashboard.json`
   откатывается к `default.json`; отсутствие `www/index.html` ведёт в
   `/recovery`; отсутствие `protocol.json` отключает декодирование, но не сеть.
3. **Публичные контракты — только наблюдаемые.** В спеках фиксируются маршруты,
   поля JSON и реакции, а не конкретные классы.
4. **Store — только чтение.** Приватные спеки `vuesp-workspace` не копируются
   в этот репозиторий; ссылка идёт по spec id.

## Non-goals

- Описание внутренней архитектуры C++ и конкретных функций.
- Полный контракт бинарного протокола — он будет отдельной спекой store.
- Требования к конкретным платам за пределами списка поддерживаемых.
- Изменения поведения прошивки или UI.

## Risks

- Спеки могут отставать от кода: любое изменение поведения обновляет
  соответствующую спеку в том же change.
- Дублирование с DOCS.md: DOCS остаётся пользовательской документацией, спеки —
  контрактом для разработки и агентов.
