# Web-интерфейсы

## Тезисы

1. **Гиперминимализм / успокаивающий дизайн.** Большие поля, один сильный акцент, ясная иерархия. Не прятать базовую навигацию ради «чистоты».
2. **Производительность как входной билет.** Скорость и вес страницы — необходимость, а не бонус.
3. **Типографика как акцент.** Крупные заголовки и текст как часть визуального языка, но без ущерба читаемости.
4. **Глассморфизм взрослеет.** Уместен в панелях, оверлеях и вторичных элементах. Не подходит для длинных текстов и критичных форм.
5. **Цвет: 60-30-10.** 1–2 акцентных цвета, градиенты со смыслом, цвет как инструмент навигации.
6. **Mobile-first.** Более половины трафика — мобильные; базовые стили для узкого экрана.
7. **AI и Zero UI.** Голос, жесты и контекстные сценарии; экран перестаёт быть единственным каналом.
8. **Доступность по умолчанию.** Контраст, клавиатура, альтернативные тексты, WCAG 2.2.
9. **Экологичность.** Статика вместо тяжёлого видео, оптимизация изображений, тёмная тема на OLED.

## Чеклист

### 1. Анализ
- [ ] Целевая аудитория и сценарии (jobs-to-be-done).
- [ ] Конкурентный анализ с фокусом на производительность и доступность.
- [ ] Бренд-атрибуты и 1–2 акцентных цвета (60-30-10).

### 2. Информационная архитектура
- [ ] Иерархия от общего к частному, не более 3–4 кликов до цели.
- [ ] Mobile-first навигация; основные действия в thumb zone, кнопки ≥ 44 px.
- [ ] Стеклянные оверлеи читаемы поверх любого фона.

### 3. Визуальный концепт
- [ ] Гиперминимализм: большие поля, один акцент, пустота как слой.
- [ ] Системный шрифт с высокой читаемостью; акцидентная типографика только для заголовков.
- [ ] Тёмная и светлая темы параллельно, dark-first.

### 4. Дизайн-система
- [ ] Токены: цвет, типографика, отступы (кратные 4 px), радиусы, тени, движение.
- [ ] Компоненты с состояниями default, hover, active, disabled, error.
- [ ] Анимация только целенаправленная, длительность несколько сотен мс.

### 5. Доступность и производительность
- [ ] Контраст ≥ 4.5:1 / ≥ 3:1, клавиатура (Tab, Enter, Esc, стрелки), ARIA.
- [ ] SVG для иконок, WebP/AVIF для фото, скелетоны при загрузке.
- [ ] Ленивая загрузка и минимизация запросов.

### 6. Прототип и тест
- [ ] Интерактивный прототип со всеми состояниями.
- [ ] Usability-тест на desktop и мобильных.
- [ ] Проверка скринридером и с отключёнными изображениями.

### 7. Передача
- [ ] Спецификации с токенами для Tailwind/CSS-переменных.
- [ ] Новый компонент — только через дизайн-систему.

## Типовые ошибки

- скрытая навигация на мобильном;
- несколько равнозначных акцентов;
- произвольные цвета и размеры;
- формы без ошибок и подсказок;
- перегруженные таблицы без приоритета колонок.
