# Промышленные интерфейсы (HMI / SCADA)

## Тезисы

1. **Интерфейс — рабочий инструмент, не картинка.** Считывание за доли секунды в любых условиях; минимум декора, без фотореализма и мигания в нормальном режиме.
2. **High Performance HMI.** Иерархия Level 1 (обзор) → Level 2 (зона) → Level 3 (агрегат) → Level 4 (детализация).
3. **Единый визуальный язык.** Стандартные символы, одинаковая логика состояний и управления.
4. **Навигация и иерархия.** От свода к параметру; фиксированные панели навигации; оператор всегда знает, где он.
5. **Управление авариями.** ANSI/ISA-18.2. Не всё отклонение — авария. Цвет + форма + текст, не «новогодняя ёлка».
6. **Цвета и контраст.** Не более 5–7 цветов состояния. Контраст критичных показателей ≥ 10:1.
7. **Стандарты.** ISA-101, NUREG-0700, ISO 11064, ГОСТ Р ИСО 9241-303, IEC.
8. **Тёмная и светлая темы.** Обе версии, выбор оператора.
9. **Мобильные и сенсорные HMI.** Респонсив для мониторинга вне цеха; кибербезопасность (DMZ, VPN); тактильная обратная связь для критичных функций.
10. **Главное правило.** Если оператору стало удобнее — это важнее дизайн-премии.

## Чеклист

### 1. Анализ и стандарты
- [ ] Отрасль, объект, тип панели: стационарная HMI, сенсорная, мобильный мониторинг.
- [ ] Применимые стандарты: ISA-101, NUREG-0700, ISO 11064, ГОСТ, ANSI/ISA-18.2.
- [ ] HMI philosophy и style guide: цвета, шрифты, размеры, навигация, символы.

### 2. Информационная архитектура
- [ ] Четыре уровня: обзор → зона → агрегат → параметр.
- [ ] На обзоре только состояние ключевых систем: норма / отклонение / внимание.
- [ ] Нормальное состояние не конкурирует с аварией.
- [ ] Фиксированные навигационные панели.

### 3. Визуальный язык
- [ ] Библиотека символов с единой логикой состояний.
- [ ] 5–7 цветов состояния; авария дублируется формой и текстом.
- [ ] Контраст ≥ 10:1 для критичных показателей; читаемость с рабочего места.
- [ ] Светлая и тёмная темы.

### 4. Компоненты и управление
- [ ] Read-only и editable визуально различаются.
- [ ] Числовые поля с шагом и min/max; подтверждение изменения.
- [ ] Без фотореализма и мигания в норме.
- [ ] Тренды на месте, а не отдельными экранами.

### 5. Аварии и безопасность
- [ ] Приоритизация тревог по ANSI/ISA-18.2.
- [ ] Авария: цвет + иконка + текст + переход к причине.
- [ ] Аварийная остановка и критичные функции защищены от случайного нажатия.

### 6. Удалённый доступ
- [ ] Адаптация критичных экранов для мобильных и сенсорных панелей 7–17".
- [ ] DMZ, VPN, разделение read/write.

### 7. Тест
- [ ] Прототип в Figma или редакторе SCADA.
- [ ] Тест с операторами: скорость обнаружения аномалии, возврат на уровень выше.
- [ ] Реальные условия: освещение, пыль, вибрация, расстояние.

### 8. Сопровождение
- [ ] Management of change: новый экран проходит через style guide.
- [ ] Обучение операторов и обратная связь через 2–4 недели.

## Типовые ошибки

- всё мигает красным;
- цвет — единственный код;
- декоративные 3D и фотореализм;
- скрытая навигация в кризисе;
- редактируемые поля выглядят как read-only;
- нет min/max и подтверждения записи.
