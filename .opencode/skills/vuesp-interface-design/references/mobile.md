# Мобильные интерфейсы

## Тезисы

1. **Thumb-first.** Bottom tab bar на 3–5 целей, FAB, bottom sheets вместо полноэкранных модалок, поиск ближе к клавиатуре.
2. **Размер целей.** Минимум 44×44 pt (iOS) / 48×48 dp (Android), расстояние между целями ≥ 8 dp.
3. **Платформенные гайдлайны.** iOS — HIG (SF Pro, Tab Bar, swipe back). Android — Material 3 Expressive (Predictive Back, Navigation Drawer). При кроссплатформе — единая база с платформенными вариантами ключевых взаимодействий.
4. **Доступность как закон.** European Accessibility Act действует с июня 2025 для многих приложений в ЕС. VoiceOver/TalkBack, контраст в обеих темах, максимальный динамический размер шрифта.
5. **Безпарольный вход.** Passkeys (FIDO2/WebAuthn), Face ID / отпечаток / PIN. Fallback — код или магическая ссылка.
6. **Прогрессивный онбординг.** Приложение можно использовать сразу; функции объясняются в момент значимости; разрешения — только когда очевидна польза.
7. **Скорость как дизайн.** Скелетоны, оптимистичные обновления, offline-first, perceived speed.
8. **ИИ-персонализация.** Адаптивный макет под поведение, критические решения — с человеком в петле.
9. **Состояния экранов.** Загрузка, пусто, заполнено, ошибка с действием.
10. **Внешние поверхности.** Виджеты, Live Activities, ongoing notifications — ценность без открытия приложения.

## Чеклист

### 1. Платформы
- [ ] iOS / Android / кроссплатформа.
- [ ] Ключевые сценарии: в пути, одной рукой, прерывистый интернет.
- [ ] HIG и Material 3; где нужны нативные паттерны, где унификация.

### 2. Навигация
- [ ] Все основные разделы за 1 тап.
- [ ] Bottom tab bar 3–5 целей с иконкой и текстом.
- [ ] Основные действия в нижней половине экрана.
- [ ] Bottom sheets для фильтров, настроек и подтверждений.
- [ ] Без гамбургер-меню для первичной навигации.

### 3. Визуальный стиль
- [ ] Один экран — одно основное действие, много воздуха.
- [ ] Тёмная тема по умолчанию или равнозначные темы; контраст в обеих.
- [ ] Единый набор иконок; у иконки без текста есть метка для скринридера.

### 4. Компоненты
- [ ] Токены цвета, типографики, отступов 4 px, радиусов, elevation.
- [ ] Состояния полей: default, focus, filled, error, success.
- [ ] Правильные клавиатуры: email, phone, number, date picker.
- [ ] Haptics на ключевые действия.

### 5. Доступность и безопасность
- [ ] Passkeys/биометрия как основной вход; пароль — fallback.
- [ ] VoiceOver/TalkBack с осмысленными метками.
- [ ] Максимальный размер шрифта и Reduce Motion.
- [ ] European Accessibility Act для рынка ЕС.

### 6. Тест
- [ ] Состояния: загрузка, пусто, заполнено, ошибка.
- [ ] Реальные iPhone и Android, не только эмуляторы.
- [ ] Одной рукой: все основные действия достижимы большим пальцем.
- [ ] Авиарежим и слабый интернет.

### 7. Передача
- [ ] Спецификации с платформенными адаптациями.
- [ ] Метрики: время до первого действия, отказы на онбординге, crash-free sessions.

## Типовые ошибки

- цели меньше 44 px;
- скрытые жесты без альтернативы;
- полноэкранные модалки для простых подтверждений;
- текст, который ломается при увеличенном шрифте;
- цвет как единственный индикатор состояния.
